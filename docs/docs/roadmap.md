# Roadmap

The current roadmap lives in the repo as
[ROADMAP.md](https://github.com/Sigilweaver/DICOM-Atlas/blob/main/ROADMAP.md).

Headline near-term items:

- Add Hologic and Hitachi vendor families.
- Extend the FFI surface with iteration helpers.
- Provide a JSON-Schema-style export of `tags.dmap` for
  cross-language consumers.
- Publish a stable `dicom-map` typeshed for Python type-checkers.

Suggestions and contributions are welcome via
[GitHub issues](https://github.com/Sigilweaver/DICOM-Atlas/issues).
